# TransferLux

Сайт компанії TransferLux — пасажирські перевезення Україна — Європа.

Статичний сайт (HTML + CSS + JS), без збірки. Публікується через GitHub Pages.

- `index.html` — розмітка та українські тексти
- `css/style.css` — стилі
- `js/i18n.js` — переклади (RU, EN)
- `js/main.js` — галерея, карта, форма бронювання, меню

Telegram менеджера задається в `js/main.js` (змінна `MANAGER`) та в посиланнях `t.me/manager_bus_lux` в `index.html`.

Фото — ілюстративні, з Unsplash (вільна ліцензія). Рекомендується замінити на реальні фото автопарку.
